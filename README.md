# The 0bg Mastery

The 0bg Mastery is a Minecraft plugin that adds custom weapons to the game. It includes a variety of unique weapons, each with their own special abilities and crafting recipes. The weapons are crafted one time and can be obtained using the `/giveweapon` command. The plugin is designed to enhance the gameplay experience by providing new tools and mechanics for players to explore.

## Install

1. Download the plugin JAR file from the [GitHub releases page](https://github.com/EnderDevelopment/The-0bg-Mastery/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Craft the weapons using the provided recipes.
2. Use the `/giveweapon <weapon>` command to obtain a specific weapon. Replace `<weapon>` with one of the following: `bloodscythe`, `thundermace`, `catclaw`, `glitchdagger`, `lightblade`, or `soniccrossbow`.
3. Equip the weapons and use their special abilities in-game.
